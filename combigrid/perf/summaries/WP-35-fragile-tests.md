## Change
- **SG quadrature** (`quadrature_test.cpp`): the 6 integrands whose integral can cancel (sin on [a, b] 1D / 3D, a x + b on [0, 1] / [a, b], x^k on a cube, random polynomial; equi + cc suites) are checked by `checkIntegral`: |Q − I| ≤ relTol · M with M = ∫|f| (or an upper bound: |a|/2 + |b|, ∏ (2 − cos a − cos b), ∏ (b^{k+1} + |a|^{k+1})/(k+1), Σ|c_t| ∏ 1/(k+1)). Same relTol as before (percent → fraction); for f of one sign M = |I|, i.e. unchanged. Bodies moved into shared helpers (same draw order: old seeds replay the same cases); `withClockSeed` / `withSeeds`; 10 `*_pinned_seeds` cases with 14 seeds that failed before (incl. 1793379453, 1794588878).
- **Cache spill** (`cached_source_function_test.cpp`): `shared_cache_and_concurrent_operator_calls` and `spilling_at_many_threads` use `withSmallMemory`: 16 shards × 8 KiB = one 128-record chunk per shard → at most 2048 records in memory whatever the point bits (6785 distinct points); `BOOST_REQUIRE` records beyond memory before checking `diskHits`; also `entries > 0`.
- **Adaptive** (`adaptive_cached_source_function_test.cpp`): `concurrent_operator_calls_on_one_function` first calls at 1 thread (cold: decision on the miss overhead) and `BOOST_REQUIRE`s mode None; the concurrent calls then switch by count-based probes; check `modeSwitches > afterFirst` (21 calls). It and `cheap_function_is_switched_off_and_probed` use `negligibleFunc` (x₀ + 0.5 x_{d−1}) instead of `cheapFunc` (audit: latent flake, below).
- **Pinning** (`grid_storage_pinning_test.cpp`, first round, superseded by the third round below): bitwise hashes of `cc` / `mixed` only `#ifdef USE_EIGEN`. `combigrid/perf/README.md` Pitfalls updated (no known flaky test; seed replay).
- **Follow-up, CC fallback** (library, `clenshaw_curtis_quadrature_rule.cpp`, only without `USE_EIGEN` / `USE_ARMADILLO`, e.g. `compileDebug.sh`): `genWeightsNaiveInplace` took the cosines from the Chebyshev recurrence, whose error grows with its length (1.4e4 eps / m at 2049 nodes; bound 8). Now a table cos(2 pi r / m) with exactly reduced arguments (O(m) `std::cos`) + `CompensatedSum` per s_k (O(m^2) as before), k <= m/2 written with the mirror image (symmetric bitwise, as the FFT path); `buildEvenInput` shared with the FFT path (moved out of its `#ifdef`). FFT path unchanged. Test: `large_rules_…` runs 32769 / 131073 nodes only with an FFT backend (O(n^2), as the Fejér test).
- **Third round, pinning without stored bit patterns** (owner decision; replaces the second round's machine gate `BUILD_HASHES_PINNED` / `__znver3__`): `grid_storage_pinning` stores per configuration the point hash (bitwise, unchanged: all 252 equal) and the values of all operator results — quadrature (scalar + 3 outputs), `interpolate` / `interpolateLinear` (scalar + 3 outputs) at 2 points, SG and DSG (before: SG vector interpolations not pinned) — checked by |r − g| ≤ 1e-12 (1 + |g|); 4896 values, generated by `SGPP_PRINT_GOLDEN=1` (prints the table entries) with the debug build; the 576 SG interpolation values agree with the original (pre-WP-18) recording to 1.2e-15. No `#ifdef` / skips. `quadrature_weights_test.cpp`: `CC_PIN_HASH_DEBUG` + hash removed (accuracy vs. long double is in the CC rule tests); its in-build check genWeightsInplace == genWeights bitwise for 17 counts up to 32769 kept as `Clenshaw_Curtis_Weights_Inplace_Equal_Weights_Bitwise`. `perf/README.md` Pitfalls: snapshot `perf_reference` diff for bitwise claims. `module-reference.md` updated.
